# 🚀 Assistente de Roteiro Viral LLM

## 💡 Visão do Projeto (Por que isso importa)
Este repositório é o blueprint estratégico para um Agente de IA (Large Language Model - LLM) focado em revolucionar a criação de conteúdo para mídias sociais (TikTok, Reels, Shorts). O objetivo é automatizar a geração de roteiros de vídeos curtos (idealmente 45 segundos) com alta qualidade de engajamento e tom nativo da plataforma.

## 🔑 Pilares Estratégicos (Como a IA será utilizada)
1. **Engenharia de Prompt Mestre:** O sucesso dependerá de um prompt base que garanta o tom viral e a estrutura de tempo.
2. **RAG/Few-Shot Learning:** Uso de uma biblioteca de "roteiros de sucesso" para garantir a consistência de estilo.
3. **Funcionalidade Prática:** Entrega de um roteiro pronto para ser lido e produzido, incluindo métricas como estimativa de tempo.

## 📋 Próximos Passos (Backlog - Prioridades do Arquiteto)
1. **[P1 - URGENTE]** Criar e Testar o Prompt Mestre de Tom "Viral".
2. Definir Estrutura Roteiro (45s): Gancho, 3 Pontos, CTA.
3. Coletar 10 Exemplos Few-Shot de Roteiros de Sucesso.
4. Requisito: Inclusão de Estimatativa de Tempo de Fala.
